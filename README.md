# Market Data Explorer

How do volatility and total return differ across 6 to 8 assets from 2020-01-01 to 2026-01-31, and is the data clean enough to build a backtester and forecasting model on? The project downloads daily price data, cleans it with reproducible code, and explores it with labeled charts and summary statistics. It is observational only. Out of scope: trading signals, intraday data, and forecasting. Done means: a fresh clone reproduces the results, the data passes documented quality checks, the analysis table and charts are delivered, and the README reports real numbers and honest limitations. This is educational research, not trading advice.
